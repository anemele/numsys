# Numeral System

A numeral system is determined by a non-repeated character sequence. It is a symbolic system.

A length=n numeral system has n-1 sub-system, as known as base.
For example, system `[0123456789ABCDEF]` has well known dec/hex/bin bases.

This crate provides a library and a cli application. See `./examples` or run `numsys help` for more infomation.
